# Lastica Movies (Android starter)

A native Android UI starter built with Kotlin and Jetpack Compose, inspired by the supplied cinematic streaming-app screenshot.

## Build APK
1. Install Android Studio (current stable) with Android SDK Platform 35.
2. Open this folder in Android Studio and allow Gradle sync.
3. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Android Studio creates the debug APK under `app/build/outputs/apk/debug/`.

This starter provides a native interface with sample placeholder titles and no movie streams, login backend, or external catalog integration yet. Add only video streams and metadata you have rights to distribute. For production, configure app signing and privacy disclosures.
